# LNReader Dictionary

Select a word and get its meaning right in the book. This script uses free dictionary API by [https://dictionaryapi.dev](https://dictionaryapi.dev/)

To use this script simply everything from `script.js` and paste it at the end of your custom JS. Custom themes might not work in older versions of app.
